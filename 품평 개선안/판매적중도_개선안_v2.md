# 27SS 판매 적중도 개선안 (v2)

> 지난 보고 피드백 반영: 품평 도구 개선 중심 → **판매 적중도 개선**을 최상위 목표로 재정리.
> 품평 도구는 목표 달성을 위한 실행 수단 중 하나로 위치 조정.

## 1. 배경 및 문제 정의
- 품평 결과(선호 순위)와 실제 판매 실적 간 괴리가 발생 → 베스트 제품 물량 부족(결품), 비인기 제품 재고 과다
- 원인 진단
  - **판단 근거가 품평 한 가지에 집중**: 과거 판매 데이터, 유통 채널 의견, 시장 트렌드가 체계적으로 반영되지 않음
  - **응답자 구성이 실제 고객과 다름**: 내부 인원 중심 의견이 한 방향으로 쏠릴 수 있음
  - **사후 검증 부재**: 품평 결과가 실제로 맞았는지 시즌 종료 후 확인·보정하는 절차가 없음
  - **물량 결정과의 연결 약함**: 품평 결과가 물량·리오더 판단 기준으로 바로 이어지지 않음

## 2. 목표
**판매 적중도 개선 → 베스트 제품 물량 확보 + 재고 리스크 최소화**

## 3. 개선 방향

### ① 판단 근거 확대 — "품평 + 데이터"
- **과거 판매 데이터 반영**: 유사 스타일·카테고리의 전 시즌 판매 실적을 품평 전에 참고 자료로 제공
- **유통 채널별 사전 의견 수렴**: 채널(온라인/백화점/아울렛 등)별 바이어·매장 의견을 사전 설문으로 수집해 반영
- **시장·고객 신호 반영**: 경쟁사 동향, 검색·리뷰 트렌드 등 외부 데이터를 보조 지표로 활용

### ② 품평 예측력 강화 — "누구의 의견을, 어떻게 볼 것인가"
- **응답자 세분화**: 부서·직급·성별·연령대별로 결과를 나눠 확인
- **의견 쏠림 점검**: 특정 집단에 편중된 결과인지 확인해 균형 잡힌 판단
- **가중치 적용**: 타깃 고객과 유사한 집단, 과거 예측이 잘 맞았던 집단의 의견에 가중치 부여 (④ 검증 결과 기반)

### ③ 물량 의사결정 연결 — "결과를 물량으로"
- 품평 + 데이터 결과를 기반으로 **제품별 물량 등급(A/B/C)** 설정
- 확신도가 낮은 제품은 초도 물량을 보수적으로, **출시 초기 판매 속도를 모니터링해 리오더**로 대응
- 베스트 예상 제품은 원단·생산 캐파 사전 확보

### ④ 사후 검증 및 보정 — "맞았는지 확인하고 다음 시즌에 반영"
- 시즌 종료 후 **품평 순위 vs 실제 판매 순위** 비교 리뷰
- 적중·미적중 제품의 원인 분석 (디자인, 가격, 채널, 출시 시점 등)
- 집단별 예측 정확도를 누적해 다음 시즌 가중치·품평 방식 보정

### ⑤ 실행 기반 — 품평 도구 개선 (수단)
- 응답자 정보 수집, 세그먼트별 집계, 결과 자동 리포트 → ①~④를 가능하게 하는 도구
- 작성·취합 자동화(반나절 → 즉시), 구글시트·메일 실시간 공유
- 모바일 UI 개선으로 참여율·응답 신뢰도 확보

## 4. 추진 단계 (안)
| 단계 | 시점 | 주요 내용 |
|---|---|---|
| 1단계 | 27SS 품평 | 응답자 세분화·세그먼트 분석, 채널 사전 설문, 과거 판매 데이터 참고 자료 제공 |
| 2단계 | 27SS 물량 확정 | 품평 결과 기반 물량 등급 설정, 리오더 기준 수립 |
| 3단계 | 27SS 판매 후 | 품평 vs 실판매 비교 리뷰, 적중·미적중 원인 분석 |
| 4단계 | 27FW~ | 집단별 가중치 적용, 시즌 데이터 누적으로 예측 모델 고도화 |

## 5. 협조 필요 사항
- 판매 데이터 제공 (영업/데이터 담당)
- 유통 채널 사전 설문 협조 (채널 담당 MD·바이어)
- 물량 등급·리오더 기준 합의 (생산·기획)
